# architect

Архитектор: изучает код проекта, находит паттерны и смешение архитектур, затем короткими вопросами помогает человеку решить, какую архитектуру он хочет, и записывает это решение в проект как цель, к которой тот стремится. Кода не трогает. Правила — в `CLAUDE.md`.

Начало: открой агента в этом репозитории — он спросит, какой проект смотреть, изучит его и начнёт с вопросов.
